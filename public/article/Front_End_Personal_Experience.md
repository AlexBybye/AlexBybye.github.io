## 很可惜，y少曾在大二有幸自学并沉迷到了前端设计之中，可能比大多数人晚了1年，也间接导致目前y少仅剩下一周时间来争取速成后端设计。
#### 但无论如何，罪不致前端，y少自学了Vue全家桶，ts,  js,并且在Github实战中，给自己和陌生人提交了许多成熟高质的前端代码。

可惜，在AI Coding发展如此迅猛的今天，纯前端显然是缺少前景的就业方向。我认为未来大概率是后端负责一站式前端，或者甚至是一个project由一个人来进行Ai Coding

没时间为逝去的前端准备而悼念了，也在此帖，对曾经的几个成熟的前端项目做个总结：

1:[AlexBybye/AlexBybye.github.io: An Vue Frame Personal Blog with excellent dramatic animationVUE框架个人博客模板](https://github.com/AlexBybye/AlexBybye.github.io)
Github pages 部署的个人博客，大多数人会使用Hexo框架去搞个人Blog，但是我更多是把这个作为自己的前端封笔之作，虽然仔细来看，代码可能效率并没有化为考虑，但无论是设计md头部进行自动化脚本处理json，或是复杂精心设计的动画，足以作为满意之作。

2：[AlexBybye/VPet: 虚拟桌宠模拟器 一个开源的桌宠软件, 可以内置到任何WPF应用程序 (github.com)](https://github.com/AlexBybye/VPet)
作为Steam比较有名的桌宠游戏，本人也是和作者进行了数个月的Github上面issue的交谈，并负责了MOD异步动态加载部分的编写
![[Pasted image 20260327091740.png]]

3：[AlexBybye/Make_Internet_Great_Again: 前端从html入门到Vue全家桶掌握教程This is just a Chinese turtorial for learning HTML CSS Javascript Vue3& Ts & Vite (github.com)](https://github.com/AlexBybye/Make_Internet_Great_Again)
依旧开源精神永存，本人全部的前端经验谈具体全部放在这个仓库之下

4：[AlexBybye/Java_MAll: 华南理工大学 网络应用架构设计This is my first full-stack project done by myself,whose function is to make users and shops more convenient. Vue3+Java的电子商城网站系统，共计约17000行代码 (github.com)](https://github.com/AlexBybye/Java_MAll)
作为CRUD传统项目，前端首次尝试了自己构建复用组件以及数据大屏。
*其余的可以说全是小打小闹，不足为观，回首前端学习，如同一杯绿茶，从容而绵长，苦口却生津。*
