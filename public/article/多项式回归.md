## 多项式回归

### 基本理念
![[多项式回归-1afe1b4931.webp]]

### 适合应用场景
1. **非线性关系建模**：适用于输入变量和输出变量之间存在非线性关系的场景，例如股票价格预测。
2. **特征工程**：通过多项式特征扩展，可以提高模型的表达能力。
### 优点
1. **灵活性高**：能够拟合复杂的非线性关系。
2. **易于实现**：基于线性回归的扩展，实现简单。
### 缺点
1. **过拟合风险**
2. **计算复杂度增加**
### Python代码示例：

```python
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
import numpy as np

# 示例数据
X = np.array([[1], [2], [3], [4]])
y = np.array([1, 4, 9, 16])

# 创建多项式特征
poly = PolynomialFeatures(degree=2, include_bias=True, interaction_only=False)
X_poly = poly.fit_transform(X)

# 创建多项式回归模型
model = LinearRegression(fit_intercept=False, normalize=False, copy_X=True, n_jobs=None)
model.fit(X_poly, y)

# 预测
X_new = np.array([[5]])
X_new_poly = poly.transform(X_new)
print("预测值：", model.predict(X_new_poly))
```
### 参数解释：

- **degree**：整数，指定多项式的最高次数。例如，`degree=2` 表示生成二次多项式特征。
    
- **include_bias**：布尔值，决定是否包含偏置项（即常数项）。如果设为 `True`，则生成的特征矩阵中会包含一列全为1的偏置项。
    
- **interaction_only**：布尔值，决定是否只生成交互特征（即不同特征的乘积项）。如果设为 `True`，则不会生成单个特征的高次项。
