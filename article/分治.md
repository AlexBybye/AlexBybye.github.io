### 将问题分解成几个子问题，递归求解每个子问题，并将子问题的解合并成整体解决方案。
## Merge-sort
从单组开始慢慢向上merge，每次merge会进行比较排序
复杂度T(n)=2T(n/2)+cn
n\*lg n
n>30优于插入排序
```C++
MERGE-SORT(A, p, r):
    if p < r
        q = FLOOR((p + r) / 2)
        MERGE-SORT(A, p, q)
        MERGE-SORT(A, q + 1, r)
        MERGE(A, p, q, r)
    end if
end
```
## Binary-search（logn）
```C++
binary_search(A, p, q,k){
    if p > q return -1;
    m = (p+q)/2;
    if A[m] == k return m;
    else if A[m] > k
        return binary_search(A, p, m-1, k);
    else return binary_search(A, m+1, q, k);
```
T(n)=T(n/2-1)+c<=T(n/2)+c =>复杂度logn
## Quick-sort
首先把数组的第一位选为pivot，然后左右两个指针开始移动，如果j指向的值比pivot小，那么把i向右移动，然后交换i和j的值。当j走到尽头后，交换p与i的值以确定pivot的正确位置。
假设我们有一个未排序的数组：`[5, 3, 8, 4, 6, 2, 7, 1]`

#### 第一轮排序

1. 选择首位元素 `5` 作为 pivot
    
2. 初始化两个指针：
    
    - `left` 指针指向第二个元素 `3`
    - `right` 指针指向最后一个元素 `1`
3. 从左向右移动 `left` 指针，直到找到一个大于等于 pivot 的元素（`8`）
    
4. 从右向左移动 `right` 指针，直到找到一个小于等于 pivot 的元素（`1`）
    
5. 交换 `left` 和 `right` 指针指向的元素：
    
    - 数组变为：`[5, 3, 1, 4, 6, 2, 7, 8]`
6. 继续移动指针并交换，直到 `left` 和 `right` 指针相遇（在元素 `2` 处）
    
7. 最后，将 pivot（`5`）与 `right` 指针指向的元素（`2`）交换：
    
    - 数组变为：`[2, 3, 1, 4, 5, 6, 7, 8]`
8. 此时，pivot 元素 `5` 已经位于其最终位置，数组被分为两部分：
    
    - 左半部分：`[2, 3, 1, 4]`（所有元素小于等于 5）
    - 右半部分：`[6, 7, 8]`（所有元素大于等于 5）
```C++
void QSort(Elem A[], int p, int q) {
    if (p >= q) return;
    Elem pivot = A[p];
    int m = partition(A, p, q, pivot);
    QSort(A, p, m - 1);
    QSort(A, m + 1, q);
}

int partition(Elem A[], int p, int q, Elem x) {
    int i = p;
    for (int j = p + 1; j <= q; ++j) {
        if (A[j] <= x) {
            ++i;
            swap(A[i], A[j]);
        }
    }
    swap(A[p], A[i]);
    return i;
}
```
复杂度nlogn~n^2
#### 既然Merge Sort和QSort的平均时间复杂度一样，那为什么STL不用Merge Sort而是用QSort呢？这里主要是考量到Merge Sort在合并时必须要开一个新空间，造成空间复杂度高；而QSort只需要一个额外元素的空间。
