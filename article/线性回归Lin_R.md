## 线性回归
### 基本理念
![[线性回归Lin-R-139576d4b2.webp]]
### 适合应用场景
1. **简单预测问题**：适用于输入变量和输出变量之间存在线性关系的场景，例如房价预测（基于面积、房间数等特征）。
2. **快速建模**：在数据量较小或特征较少的情况下，线性回归可以快速建立模型并进行预测。
### 优点
1. **简单易懂**：模型结构简单，易于解释和理解。
2. **计算效率高**：训练和预测速度较快，适合实时应用。
### 缺点
1. **线性限制**：只能处理线性关系，无法捕捉复杂的非线性关系。
2. **对异常值敏感**：异常值可能对模型的预测能力产生较大影响。

### Python代码示例：
```python
from sklearn.linear_model import LinearRegression
import numpy as np

# 示例数据
X = np.array([[1, 1], [1, 2], [2, 2], [2, 3]])
y = np.dot(X, np.array([1, 2])) + 3

# 创建线性回归模型
model = LinearRegression(fit_intercept=True, normalize=False, copy_X=True, n_jobs=None)

model.fit(X, y)

# 预测
X_new = np.array([[3, 5]])
print("预测值：", model.predict(X_new))
```

### 参数解释：

- **fit_intercept**：布尔值，决定是否计算截距项（即偏置项 b）。如果设为 `False`，则假设数据已经中心化，截距项为0。
    
- **normalize**：布尔值，决定是否对特征进行标准化。如果设为 `True`，则在回归前对特征进行标准化处理（均值为0，方差为1）。
    
- **copy_X**：布尔值，决定是否复制输入数据。如果设为 `False`，则在计算过程中直接修改输入数据。
    
- **n_jobs**：整数或 `None`，用于指定计算时使用的CPU核心数。如果设为 `None`，则只使用一个核心；如果设为整数，则使用指定数量的核心。
