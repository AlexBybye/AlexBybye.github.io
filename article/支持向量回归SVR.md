## 支持向量回归（SVR）

### 基本理念

![[支持向量回归SVR-e16c40de25.webp]]

### 适合应用场景

1. **小样本数据**：在样本数量较少的情况下，SVR表现良好。
2. **非线性回归**：通过核函数可以处理复杂的非线性关系。
### 优点
1. **鲁棒性强**：对异常值不敏感，适合处理噪声较大的数据。
2. **灵活性高**：通过选择不同的核函数，可以适应不同的数据分布。
### 缺点

1. **计算复杂度高**
2. **参数选择敏感**
### Python代码示例：
```python
from sklearn.svm import SVR
import numpy as np

# 示例数据
X = np.array([[1], [2], [3], [4]])
y = np.array([1, 4, 9, 16])

# 创建SVR模型
model = SVR(kernel='rbf', C=100, epsilon=0.1, gamma='scale', shrinking=True, tol=0.001, cache_size=200, verbose=False, max_iter=-1)
model.fit(X, y)

# 预测
X_new = np.array([[5]])
print("预测值：", model.predict(X_new))
```
### 参数解释：

- **kernel**：字符串，指定使用的核函数类型。常见的核函数有 `'linear'`（线性核）、`'poly'`（多项式核）、`'rbf'`（径向基函数核）、`'sigmoid'`（Sigmoid核）等。
    
- **C**：浮点数，正则化参数。它控制了模型对误差的容忍度。较大的 `C` 值表示对误差的容忍度较低，模型会更倾向于拟合训练数据；较小的 `C` 值表示对误差的容忍度较高，模型会更倾向于寻找一个更平滑的决策边界。
    
- **epsilon**：浮点数，定义了管的大小。它表示预测值与实际值之间的误差范围。在这个范围内的误差不会被惩罚。
    
- **gamma**：字符串或浮点数，核函数的系数。对于 `'rbf'`、`'poly'` 和 `'sigmoid'` 核函数，`gamma` 是一个重要的参数。如果设为 `'scale'`，则 `gamma` 会被自动设置为 `1 / (n_features * X.var())`。
    
- **shrinking**：布尔值，决定是否使用启发式收缩方法来加速计算。
    
- **tol**：浮点数，停止迭代的容忍度。当连续两次迭代的目标函数值变化小于 `tol` 时，迭代停止。
    
- **cache_size**：浮点数，指定内核缓存的大小（以MB为单位）。较大的缓存可以加速计算，但会占用更多的内存。
    
- **verbose**：布尔值，决定是否输出详细信息。如果设为 `True`，则在训练过程中输出详细的日志信息。
    
- **max_iter**：整数或 `-1`，指定最大迭代次数。如果设为 `-1`，则没有迭代次数限制。
