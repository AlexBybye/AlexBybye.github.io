## 1. 哈希表 什么时候用？

**满足任意一条，立刻用哈希！**

1. **要快速判断：存在 / 不存在**
2. **要记录：值 → 下标**
3. **要统计：出现次数**
4. **把大问题拆成两组，两两匹配**
5. **数组不能排序 / 不想排序 / 一排序就乱了**
6. **暴力是 O (n²)，想降到 O (n)**
#### 用 set（只存 key）

- 只关心：**在不在**
- 最长连续序列
- 重复元素判断
- 去重
#### 用 字典（key → value）

- 关心：**谁对应谁**
- 两数之和（值 → 下标）
- 四数相加 II（和 → 次数）

## 2. 双指针 什么时候用？

**满足任意一条，立刻用双指针！**

1. **在同一个数组里找 2/3/4 数之和**
2. **可以排序！排序后不影响答案**
3. **要去重！要避免重复组合**
4. **要在有序数组上逼近答案**
5. **想把 O (n²) 变成 O (n) 或 O (n log n)**

## **左右双指针（left + right）**

- 用于：**反转、两数之和、盛水最多、三数之和**
- 会**打乱顺序**

## **快慢指针（slow + fast）**

- 用于：**移动零、删除重复元素**
- **保持顺序不变**

## 四、搜索算法（DFS/BFS 大厂高频）

### 1. DFS 递归模板（回溯 / 岛屿 / 二叉树）

```Python
# 二叉树/图通用
def dfs(node, visited):
    # 终止条件
    if not node or node in visited:
        return
    visited.add(node)
    # 处理当前节点
    # 递归子节点
    dfs(node.left, visited)
    dfs(node.right, visited)
# 回溯算法（排列/组合）
def backtrack(路径, 选择列表):
    if 满足结束条件:
        res.append(路径)
        return
    for 选择 in 选择列表:
        做选择
        backtrack(路径, 选择列表)
        撤销选择
```

### 2. BFS 队列模板（层序遍历 / 最短路径）

```Python
from collections import deque
q = deque([start])
visited = set([start])
while q:
    size = len(q)
    for _ in range(size):
        cur = q.popleft()
        # 处理 cur
        for neighbor in cur.neighbors:
            if neighbor not in visited:
                visited.add(neighbor)
                q.append(neighbor)
```

## 六、链表高频操作（默写版）
```Python

# 链表节点定义
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
# 反转链表（高频！）
def reverse(head):
    pre, cur = None, head
    while cur:
        nxt = cur.next
        cur.next = pre
        pre = cur
        cur = nxt
    return pre
```

    if not root: return
